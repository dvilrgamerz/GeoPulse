GeoPulse Data Sources

GeoPulse separates live, near-live, scheduled, modeled, and reference data. Provider terms and coverage still apply.

AircraftOpenSky NetworkLive / rate-limited
SatellitesCelesTrak + SGP4Modeled position from recent orbital data
ShipsAISStreamLive viewport snapshot · API key required
EarthquakesU.S. Geological SurveyReal-time feed
DisastersNASA EONET + GDACSNear-live / source dependent
Conflict reportingGDELT GEONear-live news-location signal, not GeoPulse verification
Major eventsTicketmaster DiscoveryScheduled listings · API key required
SearchArcGIS or Photon / OpenStreetMap fallbackProvider match precision varies
Trade corridorsGeoPulse reference layerNot live vessel telemetry
Open-source acknowledgement

GeoPulse's architecture and UX were improved after studying Bilawal Sidhu's MIT-licensed God's Eye View project. GeoPulse does not bundle its restricted datasets, third-party models, branding, or promotional media.
